# jesushernan.com — prototipo

Sitio estático en Astro + Tailwind CSS. Incluye Inicio, App, Ebook, Curso y Contacto. Textos de contenido: lorem ipsum. Identidad visual e imágenes: propuesta provisional.

## Desarrollo

```bash
npm install
npm run dev
```

## Publicación

```bash
npm run build
```

Subir el contenido de `dist/` a la raíz pública configurada en Hostinger. Verificar enlaces y HTTPS en el dominio antes de abrir al público. El formulario es solo visual hasta elegir un proveedor seguro para procesar envíos.
